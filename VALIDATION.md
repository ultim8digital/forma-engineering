# neofab Studio 0.4 — дизайн и ручной редактор

Сохранены локальный запуск без аккаунта, SQLite, отдельные подключения моделей и существующие данные. Бренд и основной репозиторий переименованы в neofab; имена переменных FORMA_* и папка forma-data остаются совместимыми.

Проверки редактора:

- 6 независимых Node-тестов: порядок мировых преобразований совпадает с XYZ-вращениями CadQuery; точный предпросмотр одиночного box с локальным смещением и поворотом; сложные CSG-изменения не подменяются ложным масштабированием; сохранение root-body при переводе в редактируемый компонент; undo/redo и новая ветка истории; примитив не изменяет исходный документ и ограничения габарита.
- В браузере: создана новая ручная пластина 40×30×12; изменена на 50×35×8, положение [25,0,10], поворот Z=90°. Проверены отмена и повтор. После CAD-перестроения получены габариты [35,50,8], корректная B-Rep и сохранённые версии.
- Манипулятор перемещения: свободный жест меняет положение, красная ось меняет только X, отмена возвращает точное исходное положение.
- Две точки реальной поверхности дали измерение по сетке; визуальное сечение включается по X/Y/Z. Это не CAD-метрология и не замена чертежам.
- Сохранённый расчёт балки открылся в новой панели с прежними численными результатами. Прочность, движение и чертежи используют прежний вычислительный путь; ограничения ниже сохраняются.

Примеры остаются ручными и явно подписаны. Материалы освещения и цвет — оформление сцены, а не расчёт физических свойств. Сложные CSG/edge-изменения требуют построения CAD; экспорт черновика блокируется.

# FORMA Local 0.3 — проверка 2026-10-25

Основной путь запуска теперь локальный: Vite/React, Node.js 24, SQLite и файловые артефакты. В коде основного приложения нет Sites, Cloudflare D1/R2 или входа через ChatGPT. Провайдеры по умолчанию выключены, `.env.node` и `.dev.vars` не читаются.

Проверено на этом Mac:

- `npm ci`, `npm run setup`, TypeScript и production build.
- Локальный HTTP-сервер открывает интерфейс и API без аккаунта; 1 интеграционный Node-тест с проверками Host/Origin, записи без Origin, внутреннего токена, приватности настроек, прав 0600, смены API-адреса без переноса старого ключа, единственной активной задачи, атомарного захвата и сохранения проекта после перезапуска.
- 20 Python-тестов: прежние 16 CAD/CAE проверок плюс 4 проверки явного подключения провайдеров, HTTP-транспорта и отметки вручную заданной модели. HTTP-сервер в тестах провайдеров — явная фикстура, не настоящая модель.
- Полный локальный путь SQLite → очередь → отдельный реальный CadQuery-процесс → сохранение и чтение 13 артефактов для каждого случая: консольная балка `complete`, ползун со столкновением `needs_review`, замкнутый четырёхзвенник `needs_review` с корректным замыканием. Всё это выполняется без ИИ.
- В браузере студия открылась сразу на localhost; отдельно включён Codex CLI. Его живой каталог вернул 7 моделей. На обнаруженной `gpt-6.1-sol` выполнен настоящий запрос о пластине 50×30×5 мм: одна попытка, 12.75 с, 1 тело, 5 геометрических проверок, сохранённая версия и CAD-файлы. Это тест работоспособности, не инженерная аттестация модели.

Настоящая генерация через собственный API или Ollama / LM Studio в этой проверке не выполнялась: сервер модели и ключ не предоставлены. Их протокол проверен HTTP-фикстурой. Численные и производственные ограничения 0.2 сохраняются. Облачные проекты автоматически не перенесены.
