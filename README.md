# neofab Studio · 0.4

[![Validate neofab](https://github.com/ultim8digital/neofab/actions/workflows/ci.yml/badge.svg)](https://github.com/ultim8digital/neofab/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**Локальная open-source студия для деталей и механизмов. Без аккаунта neofab, входа через ChatGPT и обязательного облака.** Проекты, версии, CAD-файлы и настройки хранятся на твоём компьютере. Модели подключаются отдельно: собственный API, локальная модель или установленный и авторизованный CLI.

**Local-first CAD / CAE workbench. No neofab account or hosted login required.** [English setup guide](docs/SELF_HOSTING.md) · [Contributing](CONTRIBUTING.md) · [Security](SECURITY.md).

## Быстрый запуск

Требуются **Node.js 24+**, **Python 3.12** (либо установленный `uv`, который подготовит Python). На Ubuntu сначала установи `libglu1-mesa` и `libgl1`. macOS и Linux — целевые платформы; Windows пока не проверен.

```sh
git clone https://github.com/ultim8digital/neofab.git
cd neofab
npm ci
npm run setup
npm start
```

Открой **http://localhost:5173**. Первый запуск сам соберёт интерфейс, создаст SQLite-базу и запустит CAD-узел. Регистрация, cookies входа и ручное создание секретов не нужны. `Ctrl+C` останавливает сервер и его вычислительный процесс. После изменения исходников выполни `npm run build` перед `npm start`. Для разработки — `npm run dev`.

## Рабочее пространство

- Большой 3D-холст, плавающие панели сборки и свойств, отдельная компактная строка ИИ. На узком экране свойства открываются по кнопке.
- Выбор деталей в сцене и дереве, скрытие, изоляция, разнесённый вид, фокус, сетка, прозрачный и каркасный режимы.
- Осевые манипуляторы перемещения / поворота с привязкой 1 мм / 5°. Числовой ввод положения и углов; значения можно менять перетаскиванием подписи оси.
- Редактирование размеров box, цилиндров, глубины и точек контура выдавливания, скруглений и фасок; добавление примитивов, отверстий и операций, копирование и удаление деталей, редактируемая JSON-схема.
- Отмена и повтор до 60 изменений. Ручная история сохраняется и после построения новой CAD-версии. Готовые версии открываются отдельно.
- Измерение между двумя точками и визуальное сечение **по полигональной сетке**. Они не заменяют точную CAD-метрологию и производственные чертежи.
- Положение и поворот показываются сразу; для одиночного box есть точный геометрический предпросмотр размеров. Изменение сложных CSG-операций требует построения CAD. Предпросмотр помечен; экспорт файлов заблокирован до подтверждённого построения.
- Цвета и видимость деталей запоминаются в браузере для каждого проекта; это оформление сцены, а не сертифицированные свойства материала.

Горячие клавиши: `V` — выбор, `G` — перемещение, `R` — поворот, `M` — измерение, `F` — фокус на детали, `X` — прозрачность, `⌘/Ctrl Z` — отмена, `⇧ ⌘/Ctrl Z` — повтор, `⌘/Ctrl D` — копия.

Проект ранее назывался FORMA. Папка `forma-data/` и переменные окружения `FORMA_*` сохранены для совместимости с существующими установками; переименование не перемещает и не удаляет данные.

## Подключение моделей

В студии открой **Подключения → Настроить API, локальную модель и CLI**. Все провайдеры первоначально выключены. Сохрани нужные подключения; каталог обновится в течение 10–30 секунд. Затем выбери провайдера и модель.

- **Локальная модель:** запусти сервер Ollama / LM Studio и загрузи модель. Типовые адреса — `http://127.0.0.1:11434/v1` и `http://127.0.0.1:1234/v1`. Для большинства локальных серверов ключ не нужен.
- **Собственный API:** укажи URL совместимого сервера и свой ключ. Поддерживаются `GET /models` и `POST /chat/completions`. Если каталог не поддерживается, можно явно задать идентификатор модели. Такая модель помечается как заданная вручную, а не проверенная. Каталог ограничен 100 моделями на провайдера; явно указанная модель включается в этот список.
- **Codex CLI:** установи CLI отдельно, выполни `codex login` в терминале и явно включи подключение.
- **Claude Code:** установи CLI отдельно, выполни `npm run setup:claude`, затем `claude auth login` и включи подключение. Дополнительный SDK нужен только для каталога моделей.

neofab не включает подписки, API-кредиты, модели или вычислительные мощности. Доступ к выбранному провайдеру настраивается отдельно. Успешное обнаружение модели не гарантирует квоту или качество инженерного результата. Облачному API / CLI передаются задача и CAD-спецификация выбранного проекта; при локальной модели этот запрос остаётся на её сервере.

**Без ИИ работают:** учебные примеры, импорт JSON, параметрическое редактирование, CAD-построение, инженерные расчёты и экспорт. Ручные образцы явно обозначены; они не выдаются за результат модели.

## Что умеет студия

- Параметрические детали и сборки до 24 компонентов; отдельные STEP/STL, BOM CSV, архив деталей, разнесённый вид и неизменяемые версии.
- Декларативная схема CAD: box, cylinder, extrusion, fillet, chamfer. CadQuery / OpenCascade строит B-Rep в отдельном процессе с таймаутом; модель не исполняет произвольный Python.
- Проверка тел, габаритов, пропущенной геометрии и объёмных пересечений; до трёх попыток исправления спецификации моделью.
- Прочность отдельной детали: Gmsh → T4 FEM → SciPy sparse; напряжения von Mises, перемещения, реакции, запас и сравнение двух сеток. Материал, источник свойств, нагрузки и закрепления задаются явно.
- Кинематика дерева и численное замыкание контуров; вращательные, поступательные и жёсткие связи, пределы шарниров, проигрыватель и B-Rep столкновения в выбранных положениях.
- Три ортогональных вида, габариты, цилиндрические диаметры и координаты осей; числовые допуски и проверка интервалов; PDF A3, DXF и CSV размеров.
- REST API и восемь инструментов MCP для внешних локальных агентов.

## Данные и настройки

По умолчанию в `forma-data/` рядом с исходниками:

| Файл / папка | Содержимое |
| --- | --- |
| `forma.sqlite` (+ WAL/SHM во время работы) | Проекты, версии, очередь и API-токены в виде хешей |
| `artifacts/` | STEP, STL, PDF, DXF-архивы и отчёты сохранённых версий |
| `cad-work/` | Рабочие файлы CAD-процессов |
| `providers.json` | Подключения и ключи; файл с правами 0600, ключи не возвращаются в интерфейс |
| `.worker-token` | Автоматически созданный внутренний токен узла |

Папка исключена из Git. Для резервной копии останови студию и скопируй всю папку. При смене адреса API старый ключ не переносится автоматически. В окружении можно задать `FORMA_DATA_DIR` (другую папку), `FORMA_PORT` (порт) и `FORMA_PYTHON` (абсолютный путь Python с CAD-зависимостями). См. [.env.example](.env.example); файлы `.env.node` и `.dev.vars` из облачной версии не читаются.

Версия 0.3 начинает с новой локальной базы. Автоматического переноса данных из облачной версии 0.2 нет. Старые исходники доступны в теге `v0.2.0`.

## Границы инженерных проверок

Прошедшая проверка **не является разрешением на изготовление**. FEA покрывает отдельную деталь, малые деформации и изотропную линейную упругость. Контакты сборки, пластичность, усталость, потеря устойчивости и температура не решаются. Пики у заделки могут быть сингулярными; нужна сходимость сетки. Для FDM результат всегда условный: анизотропия, заполнение и прочность между слоями не вычисляются.

Движение проверяется максимум в 61 дискретном положении. Между ними столкновение возможно; динамики, трения и зубчатого зацепления нет. Чертежи имеют статус **DRAFT**; сложные профили, GD&T, базы, доступ инструмента и достижимость допусков требуют проверки конструктора. DXF содержит аппроксимированные проекции с отклонением 0,01 мм; точная геометрия — в STEP. CAM, G-code, STEP-импорт и произвольные поверхности пока не реализованы.

## API и MCP

Локальный сервер слушает только `127.0.0.1`. Браузер на этом компьютере открывает его без аккаунта. Host и Origin проверяются; запросы с других сайтов отклоняются. Для записи из скрипта нужен совпадающий локальный `Origin` или API-токен. Маршруты CAD-узла требуют отдельного внутреннего токена. Настройки провайдеров недоступны по токену агента / узла.

Основные маршруты: `/api/state`, `/api/projects`, `/api/projects/:id/jobs`, `/api/jobs/:id`, `/api/models`, `/api/providers`, `/api/artifacts/:revisionId/:filename`. Задания асинхронные. Поля `provider`: `manual`, `local`, `api`, `codex`, `claude`; `model` — идентификатор выбранной модели. Не подключённый провайдер отклоняется; ИИ-ошибка не заменяется ручной заготовкой.

Студия должна быть запущена перед MCP:

```sh
npm run mcp
```

Stdio-мост автоматически читает внутренний токен из той же папки данных. Для другого порта укажи `FORMA_URL`, для другой папки — `FORMA_DATA_DIR`. Для отдельного отзываемого доступа можно создать токен агента в интерфейсе и передать его через `FORMA_AGENT_TOKEN`. Конфигурация клиента:

```json
{"mcpServers":{"forma":{"command":"/absolute/path/neofab/.venv/bin/python","args":["/absolute/path/neofab/worker-node/mcp_server.py"]}}}
```

Это локальная студия одного доверенного владельца. Доступ через LAN, публичный reverse proxy и многопользовательская работа не поддерживаются. Не публикуй этот сервер в интернет без отдельной аутентификации и изоляции исполнения.

## Проверки и лицензия

```sh
npx tsc --noEmit
npm run build
npm run test:local
npm run test:editor
npm run test:engineering
# При запущенной студии, три реальных CAD / CAE примера:
.venv/bin/python tests/exercise_engineering_api.py
```

CI проверяет сборку, локальный запуск, сохранение данных и инженерные задачи на чистом Ubuntu. Численные результаты и фактические ограничения — в [VALIDATION.md](VALIDATION.md). HTTP-фикстуры явно отделены от реального вывода модели.
